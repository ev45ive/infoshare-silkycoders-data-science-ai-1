# Plan sezonu AW26 (wersja robocza, 3 sierpnia 2026)

Wstępny plan merchandisingu przewiduje przegląd wybranych kurtek pod koniec września. Rabat sezonowy może wynieść 20–30%, jeśli pokrycie zapasu i sygnał sprzedaży uzasadnią działanie. Plan nie jest zatwierdzeniem konkretnej przeceny. Brak tutaj dostaw po 28 września oraz prognozy pogody.
